# Lucide-Icons für die Designübergabe

SVG-Originale aus [Lucide](https://github.com/lucide-icons/lucide/tree/58ef6830c6fdf6374b751ab28b147a921bd31b34/icons), festgehalten auf Commit `58ef6830c6fdf6374b751ab28b147a921bd31b34`.

89 Icons, 24 × 24 als gemeinsames Raster. Paper verwendet 16/20/24 Punkte für UI-Symbole, mindestens 44 Punkte für Bedienflächen und Strichstärke 1,8. Geräteillustrationen verwenden dieselben Originalpfade. Diagramme sind eigene Datenvisualisierungen.

[LICENSE](LICENSE) enthält die ISC-Lizenz sowie die MIT-Hinweise für Feather-abgeleitete Icons. Beide Hinweise bleiben bei Weitergabe erhalten. Die App verwendet bereits `lucide_icons_flutter` 3.1.17; dessen [Paketlizenz](FLUTTER-PACKAGE-LICENSE) liegt ebenfalls bei. SVG-Quelle und Flutter-Paket sind getrennte Versionsstände. Aktuelle Namen wie `face-slightly-smiling`, `footprints` und `circle-question-mark` werden bei der Umsetzung auf vorhandene Glyphen (`smile`, `footprints`, `circleHelp`) abgebildet oder als beiliegendes Original-SVG verwendet. Keine App-Abhängigkeit wurde geändert.
